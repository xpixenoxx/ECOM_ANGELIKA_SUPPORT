# Angelika Fashions - World-Class Premium E-Commerce Platform

## Vision
Build the **best-in-class premium e-commerce experience** for an Indian women's ethnic wear brand (kurtis, salwars, lehengas, sarees, dupattas) founded by **Vidhya**. Not generic — every detail customized, premium transitions, smooth UX, unique brand identity.

## Core Constraints
- **Design-first**: Premium, customized, no generic AI templates
- **Performance**: Perfect Lighthouse scores, smooth 60fps animations
- **Accessibility**: WCAG 2.1 AA minimum
- **Context continuity**: Every chat must feel like continuation — all decisions documented in memory
- **Tech stack**: Next.js 14 + React 19 + TypeScript + Supabase + Tailwind + Framer Motion
- **Deployment**: GitHub → Vercel (auto-deploy) + GoDaddy (domain)
- **Admin**: Non-technical content management for Vidhya

## Founder Context
- **Vidhya** runs the brand personally — her voice, curation, "Vidhya's Picks" are central
- Indian ethnic wear focus with modern premium positioning
- WhatsApp commerce integration critical for Indian market
- Size finder with body shape analysis already implemented (enhance it)

## Differentiation Strategy
- Editorial/content-first commerce (styling guides, video)
- Personal founder connection (Vidhya's notes in Hindi/English)
- AI-powered size finder + style quiz
- Community/loyalty beyond points (styling sessions, early access)
- Post-purchase experience that builds lifetime value
